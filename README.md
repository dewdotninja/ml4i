### คำนำ

นิยามโดยย่อของการเรียนรู้ของเครื่อง (ML : Machine Learning) จากวิกิพีเดียคือ สาขาย่อยหนึ่งของปัญญาประดิษฐ์ (AI : Artificial Intelligence) และวิทยาศาสตร์คอมพิวเตอร์ ที่เน้นการสร้างอัลกอริทึมและโมเดลคำนวณ เพื่อให้คอมพิวเตอร์สามารถเรียนรู้ จดจำรูปแบบ และปรับปรุงประสิทธิภาพในการทำงานได้เองจากข้อมูลหรือประสบการณ์ โดยไม่ต้องอาศัยการเขียนโปรแกรมสั่งการแบบตายตัวทีละขั้นตอน

ปัญหาหนึ่งที่ผู้เขียนพบในฐานะเป็นผู้สอนในสาขาวิศวกรรมไฟฟ้าเครื่องกลการผลิต ภาควิชาวิศวกรรมเครื่องกล คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ ในรายวิชาที่เน้นการประยุกต์ ML กับงานอุตสากรรมด้านการผลิต การควบคุมอัตโนมัติ และหุ่นยนต์ คือการหาหนังสือตำราเรียนที่มีตัวอย่างการใช้งานตรงกับความต้องการ เพราะหนังสือส่วนใหญ่จะเขียนสำหรับผู้อ่านทั่วไปที่สามารถเข้าใจการจำแนกชนิดดอกไม้ ตัวเลข 0 - 9 เขียนด้วยลายมือ เสื้อผ้า สัตว์เลี้ยง ได้โดยง่าย แต่สำหรับผู้เรียนในสาขาวิศวกรรมศาสตร์มักจะมีส่วนที่ต้องใช้ทักษะเพิ่มเติม เช่นการสร้างฟีเจอร์ (feature) สำหรับการพยากรณ์อาการมอเตอร์ก่อนที่จะเสีย เพื่อการบำรุงรักษาเชิงป้องกัน (preventive maintenance) ซึ่งอาจมีการใช้การแปลงฟูเรียร์ (Fourier transform) หรือวิธีการเฉพาะแบบอื่นที่ต้องอาศัยความรู้ทางคนิตศาสตร์และวิศวกรรมที่เกี่ยวข้อง หรือการปรับแต่งตัวควบคุม PID โดยใช้การเรียนรู้เสริมกำลัง (reinforcement learning) จะเกี่ยวข้องกับวิศวกรรมควบคุม  

ดังนั้นวัตถุประสงค์ของหนังสือเล่มนี้คืออธิบายหลักการของวิธีการ ML ประเภทต่างๆ ตั้งแต่แบบที่เรียกกันว่าคลาสิก จนถึงการใช้โครงข่ายประสาทเทียม โดยใช้ตัวอย่างที่เกี่ยวข้องกับงานอุตสากรรม เน้นด้านการผลิต ระบบควบคุมอัตโนมัติ หุ่นยนต์ ดังนั้นหนังสืออาจไม่เหมาะสำหรับผู้อ่านทั่วไปที่ต้องการศึกษาหลักการพื้นฐานการเรียนรู้ของเครื่อง ซึ่งปัจจุบันมีหนังสือในท้องตลาดจำนวนมากที่น่าจะตรงความต้องการมากกว่า

เนื้อหาส่วนใหญ่ของหนังสือนี้เรียบเรียงจากเอกสารภาษาอังกฤษที่สร้างขึ้นโดย Claude ซึ่งผู้เขียนใช้ในการสอนในหลักสูตรนานาชาติ โดยแปลเป็นภาษาไทยและขยายความในส่วนที่ไม่ชัดเจน แต่ละบทของหนังสือเขียนอยู่ในรูปของ จูไพเทอร์โน้ตบุ๊ก (Jupyter notebook) ซึ่งต่อไปจะเรียกเพียง "โน้ตบุ๊ก" อนึ่ง ในการแปลจะเขียนเป็นคำทับศัพท์เป็นส่วนใหญ่เพราะเป็นสากลมากกว่า เช่นคำว่า "random forest" แม้จะมีการใช้คำว่า "ป่าสุ่ม" แต่จะเลือกใช้ "แรนดอมฟอเรส" หรือใช้ตัวย่อ RF เพื่อประหยัดพื้นที่ของเอกสาร อย่างไรก็ตามจะพยายามแปลไทยคำที่เป็นที่รู้จัก หรือไม่สร้างความสับสนในการสื่อความหมาย
